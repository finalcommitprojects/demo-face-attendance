Face recognition attendance

Register students once, then mark the class present from the camera or a class photo.

Runs in your browser. Faces and the register stay on this device, and only 128 numbers per face are kept, never the photo.

    How it works

    1. Find faces. A small, fast detector finds faces in each camera frame. A slower, more accurate one is used for photos, where faces can be small.
    2. Describe each face. 68 landmarks line the face up, then a ResNet-style network turns it into 128 numbers. Photos of the same person give numbers that sit close together.
    3. Match. A face is a student's if its numbers are within 0.5 (Euclidean distance) of one of that student's saved samples, and clearly closer to that student than to anyone else. Otherwise it's "not registered".
    4. Check for a blink. A second model, MediaPipe Face Landmarker, scores how closed each eye is, from 0 to 1. A blink is a closure that opens again within 0.7 seconds. A printed photo never blinks.
    5. One face, one student. Registering a face that already belongs to another student is refused, so nobody can register for a friend.

    The full project usually adds a Python server (OpenCV and a face-recognition model, with Flask and SQLite), teacher logins, subjects and timetables, attendance percentages per student, and the report.
